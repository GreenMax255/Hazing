맵 에디터

칸을 클릭하거나 드래그해서 타일을 칠하세요. 오른쪽 클릭은 항상 지우개(0번)입니다.

1. 맵 크기



주의: 새로 만들기를 누르면 지금 그린 맵은 사라집니다. 필요하면 먼저 내보내기로 저장하시거나, 실수했다면 되돌리기(Ctrl+Z)로 복구하실 수 있습니다.

2. 타일 종류 선택

3. 화면 배율

4. 기존 맵 불러오기

game.html의 map 배열 전체(대괄호 포함)를 복사해서 아래에 붙여넣고 불러오기를 누르세요.



5. 배열 코드로 내보내기

6. 단축키 안내

  • 0 ~ 5 : 해당 번호 타일 즉시 선택
  • Shift + 드래그 : 사각형 범위 한번에 채우기
  • Ctrl + Z : 되돌리기
  • Ctrl + Y : 다시하기
  • Ctrl + 휠 : 마우스 위치 기준 확대/축소
  • 방향키 : 화면 이동(스크롤)

7. 좌표로 이동

큰 맵에서 스크롤을 계속 끌지 않고, 알고 있는 좌표로 화면을 바로 옮길 수 있습니다.

8. 미니맵 (클릭해서 이동)

흰색 테두리가 지금 오른쪽 화면에 보이는 범위입니다. 미니맵을 클릭하면 그 위치로 화면이 이동합니다.

9. 보기 옵션

예를 들어 4번(문)을 선택한 상태에서 이 옵션을 켜면, 큰 맵 안에 흩어진 문들이 한눈에 보입니다.
